# LLM 개선 실험 기록

가구 정보를 보완하고, 사례 검색·판단 절차·설명·통계모형의 예측값을 추가하면서 소비 재현 결과를 비교했습니다. 아래에는 각 시도에서 바꾼 내용과 사용한 파일을 정리했습니다. 실험마다 표본과 입력 조건에 차이가 있어 동일 표본의 연속적인 성능 추이로 읽기는 어렵습니다.

## 개선 과정

**유사 가구 사례 제공(RAG)**

실제 가구 사례를 검색해 참고하도록 했습니다. 초기 비교에서는 기본 LLM, RAG, RAG에 한국노동연구원 문헌 정보를 더한 조건을 비교했으나, 기본 LLM 대비 추가 효과는 뚜렷하지 않았습니다. [E1 결과](#e1)

사용 파일: [검색 코드](../code/phase1_rag_llm/phase1_rag_v1.py), [1-A 프롬프트](../reference_source/historical/prompts/v5_1a_original.txt), [1-B 프롬프트](../reference_source/historical/prompts/v5_1b_original.txt)

**사건 시점과 지출 분포 보강**

사건이 언제 발생했는지, 유사한 조건에서 지출이 어떻게 분포하는지를 보강했습니다. 기존 RAG보다 항목 MAE가 1-A 3.48%, 1-B 3.64% 줄었지만, 기본 LLM의 변화는 뚜렷하지 않았습니다. [E2 결과](#e2)

사용 파일: [날짜 요약](../reference_source/historical/code/event_timing_v1.py), [시점 반영 검색](../reference_source/historical/code/phase1_rag_timing_v2.py), [분포 요약](../reference_source/historical/code/spending_distribution_support_v1.py), [1-A 프롬프트](../reference_source/historical/prompts/improved_20261016_1a.txt), [1-B 프롬프트](../reference_source/historical/prompts/improved_20261016_1b.txt)

**가구 역할과 판단 절차 안내**

어떤 가구의 입장에서 무엇을 고려해야 하는지 안내하고, 가구 정보를 요약해 제공하는 조건도 비교했습니다. 역할·절차 안내 후 항목 MAE는 기존 기본 조건보다 1-A 1.79%, 1-B 2.47% 증가했고, 요약을 추가해도 일관되게 나아지지는 않았습니다. [E3 결과](#e3)

사용 파일: [1-A 프롬프트](../reference_source/historical/prompts/v6_AB_20261017_1a.txt), [1-B 프롬프트](../reference_source/historical/prompts/v6_AB_20261017_1b.txt). B조건은 같은 문안에 가구 정보 요약을 추가한 입력입니다.

**항목별 설명과 오류 검토**

모든 항목에 설명을 요청하고 원입력과 대조했습니다. 공통 A95/B33 표본에서 항목 MAE는 A 약 660원 증가, B 약 233원 감소했으나 두 차이의 95% 구간은 모두 0을 포함했습니다. 이후에는 관측 사실, 변화 방향, 조정 폭과 최종금액을 구분하는 형식으로 정리했습니다. [E4 결과](#e4)

관련 파일: [현재 응답 형식과 검사 코드](../reference_source/code/phase1_inputs/household_decision_v2.py). 이 파일은 오류 검토를 거쳐 정리한 후속 형식입니다.

**가구 상태와 표본 재점검**

목표연도의 교육·취업·주거·가구 구성을 연결하고, 확인되지 않은 지출을 0으로 단정하지 않도록 입력을 보완했습니다. 현재 결과는 기존 1-A 98가구, 교육변화 53가구, 신규 1-B 40가구를 나누어 보고합니다. 입력과 표본이 함께 바뀌었으므로 특정 수정 하나의 효과로 해석하지 않았습니다. [전체 결과표](../03_results/TABLES.md)

사용 파일: [현재 1-A 프롬프트](../reference_source/code/phase1_inputs/household_decision_1a_v3_uncertainty.txt), [현재 1-B 프롬프트](../reference_source/code/phase1_inputs/household_decision_1b_v2_target_state.txt)

**CatBoost 예측정보 제공**

CatBoost의 대상 가구별 12개 항목 예측을 참고 정보로 주고, LLM이 유지하거나 수정하도록 했습니다. 공통 96가구에서 기존 LLM보다 항목 MAE는 9.7%, 총소비 MAE는 17.1% 줄었습니다. CatBoost 단독보다 더 나은지는 뚜렷하지 않았습니다. [비교 결과](../03_results/README.md#catboost-참고-llm)

사용 파일: [입력 생성](../reference_source/code/phase1_inputs/prepare_catboost_llm_a98_20261021.py), [추가 지침](../reference_source/code/phase1_inputs/household_decision_1a_catboost_addendum_v1.txt), [분석 코드](../reference_source/code/phase1_inputs/analyze_catboost_llm_a98_20261021.py)

## 실험별 수치와 조건

금액 단위는 2023년 실질 원/월, 아래 표는 **항목 평균 MAE**입니다. 각 응답의 오차를 먼저 계산한 후 집계한 값이며, 반복 예측을 평균한 앙상블 성능이 아닙니다. 수치는 원 기록의 원 단위 반올림 값을 옮겼습니다. [집계 CSV](historical_metrics.csv)

<a id="e1"></a>
### E1 · 초기 RAG 비교 — 2026-10-15 집계

1-A 98가구, 당시 1-B 41가구 · 3조건 × 2문구 × 5회 반복

| 조건 | 1-A | 당시 1-B |
|---|---:|---:|
| 기본 LLM | 48,866 | 61,555 |
| LLM + RAG | 47,857 | 61,695 |
| LLM + RAG + KLI | 47,857 | 61,170 |

1-A의 RAG 점추정 오차는 감소했지만, 기본 대비 항목 MAE 감소 구간은 −587~2,613원으로 0을 포함했습니다. 당시 1-B에서는 RAG 오차가 소폭 증가했습니다. KLI는 한국노동연구원 문헌 정보를 추가한 조건명이며 KDI 직업별 AI 지표와 다릅니다. 당시 1-B는 사건연도 및 이후 두 해를 대상으로 하므로 현재 B40 결과와 별도 비교입니다.

<a id="e2"></a>
### E2 · 시점·분포 보강 — 2026-10-17 집계

1-A 98가구, 당시 1-B 41가구 · original 문구 · 조건별 5회 반복

| 조건 | 1-A | 당시 1-B |
|---|---:|---:|
| 기존 기본 LLM | 48,496 | 61,559 |
| 보강 기본 LLM | 48,520 | 61,792 |
| 기존 RAG | 47,894 | 62,326 |
| 보강 RAG | 46,226 | 60,055 |

RAG의 오차 감소는 A 1,668원[178, 3,563], B 2,271원[634, 4,210]으로 탐색적 95% 구간이 0을 포함하지 않았습니다. 다만 날짜·검색·분포 지침을 묶어 변경했으므로 개별 요소의 기여는 분리되지 않았습니다. 총소비 오차의 개선과 통계모형 대비 우위는 뚜렷하게 확인되지 않았습니다. E1은 두 문구를 합친 값이고 E2는 original 문구만 사용하므로 기존 점수도 다릅니다.

<a id="e3"></a>
### E3 · 역할·절차 및 가구 정보 요약 — 2026-10-17 집계

동일 개발 가구의 조건별 3회 반복 · 기본 조건은 사전 지정한 기존 반복 0·1·2 재사용

| 조건 | 1-A | 당시 1-B |
|---|---:|---:|
| 기존 기본 | 48,254 | 62,154 |
| 역할·절차 안내 | 49,118 | 63,689 |
| 역할·절차 + 가구 정보 요약 | 48,644 | 64,633 |

역할·절차 안내는 기존 대비 항목 오차가 증가했습니다. 정보 요약 추가 효과도 과제별 방향이 달랐으며, 역할·절차 조건과의 차이 구간은 두 과제 모두 0을 포함했습니다. 이는 역할·절차·중복 정리를 함께 변경한 결과이고, 이후의 구조화된 설명 형식 전체가 무효하다는 결론은 아닙니다.

<a id="e4"></a>
### E4 · 설명 확대 후 오류 점검 — 2026-10-19 집계

두 버전 모두 3회 반복이 완전한 공통 A95/B33 · B는 사건연도와 다음 해만 채점

| 조건 | 1-A | 당시 1-B |
|---|---:|---:|
| 직전 버전 | 46,943 | 60,436 |
| 전항목 설명 버전 | 47,604 | 60,203 |

항목 MAE 차이의 95% 구간은 모두 0을 포함했습니다. 오류 검토에서는 과거 고액 지출의 지속 여부, 소득 변화에 따른 조정 폭, 비정기 지출의 발생 판단을 점검했습니다. 이는 관측근거와 판단 요약을 분리하고 방향·금액 조정 근거를 구분하는 후속 입력·출력 정비로 연결되었습니다. 표의 반올림 값 차이와 원 집계의 약660원 차이는 반올림 방식 때문에 1원 다를 수 있습니다.

## 이후 확인할 점

RAG는 초기 비교와 시점·분포 보강 이후의 결과가 달랐습니다. 따라서 사례 제공 자체의 효과와 어떤 정보를 함께 제공했는지를 나누어 살펴볼 필요가 있습니다. 역할·절차 안내와 설명 요청 역시 오차의 변화뿐 아니라 설명이 실제 입력과 맞는지 함께 검토해야 합니다.

반복 응답의 일관성, 정보 조건을 바꿨을 때의 반응, 설명의 유용성, 외부 데이터셋에서의 성능을 후속 평가 항목으로 두었습니다. 도메인 파인튜닝은 검토 대상이며, 이 문서에 완료 결과로 포함하지 않았습니다. 본실험용 최종 표본 배정도 진행 중입니다.
