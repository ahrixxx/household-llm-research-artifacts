# 02. LLM 소비 재현 실험

LLM에 가구의 소득·자산·구성·과거 소비를 제공하고 12개 항목의 소비금액을 재현하도록 했습니다. 개발 단계에서는 입력 정보를 보완하고, 유사 가구 사례나 판단 지침을 추가했을 때 결과가 어떻게 달라지는지 확인했습니다.

## 입력과 프롬프트 수정

처음에는 유사 가구를 찾아 참고하게 하는 RAG를 비교했습니다. 이후 사건의 시점과 지출 분포 정보를 보강하고, 가구 역할과 판단 절차를 안내하거나 항목별 설명을 요청하는 방식을 시험했습니다. 현재 입력에서는 목표연도의 가구 상태를 보완하고, 관측 사실과 금액 조정의 근거를 구분하도록 했습니다. CatBoost가 산출한 대상 가구별 소비 예측을 참고 정보로 제공하는 실험도 진행했습니다.

어떤 수정이 도움이 되었는지 확인하기 위해 [실험별 변경 내용과 결과](RESULT_LINKS.md)를 함께 남겼습니다. 표본과 입력 형식이 달라진 실험은 따로 비교했습니다.

## 비교 모형

| 모형 | 비교 목적 및 방식 |
|---|---|
| 전년 실질소비 유지 | 전년 소비가 그대로 유지된다고 가정하는 기준 |
| Ridge | L2 규제를 적용한 선형 회귀 |
| Lasso | L1 규제로 일부 변수의 계수를 0으로 만드는 선형 회귀 |
| 중앙값 회귀 | 소비금액의 중앙값을 추정하는 0.5 분위수 회귀 |
| RF-MAE | 각 나무의 말단에서 중앙값을 예측하고 나무별 예측을 평균 |
| CatBoost-MAE | 수치·범주형 정보를 활용하는 부스팅 회귀 |
| RF-MSE | 각 나무의 말단에서 평균값을 예측하고 나무별 예측을 평균하는 보조 기준선 |
| HistGBM | 입력값을 구간으로 나누어 학습하는 부스팅 회귀, 보조 기준선으로 비교 |

통계·머신러닝 모형은 학습자료로 학습시켰습니다. LLM은 파인튜닝 없이 사용하고 개발 결과를 보며 프롬프트를 수정했습니다. 같은 방식으로 학습시킨 모형끼리의 비교는 아니며, 각 방법을 이 소비 재현 과제에 적용했을 때의 성능을 비교합니다.

## 평가지표

| 지표 | 확인하려는 내용 |
|---|---|
| 항목 평균 MAE | 12개 소비항목 각각을 얼마나 정확하게 재현하는지 |
| 총소비 MAE | 12개 항목을 합한 가구의 전체 소비 규모를 얼마나 정확하게 재현하는지 |
| 평균 소비 변화와 가구 간 표준편차(SD) | 소비 변화의 평균적인 방향과 가구마다 변화 폭이 다른 정도 |
| 동일 입력의 반복 응답 표준편차(SD) | 같은 정보를 주었을 때 LLM의 답이 얼마나 달라지는지 |
| 모형 간 오차 차이의 95% 구간 | 가구 표본이 달라져도 두 모형의 차이가 유지되는지 |

MAE는 예측과 관측값의 차이를 절댓값으로 바꾸어 평균한 값입니다. 항목 평균 MAE는 가구·응답별로 12개 항목의 오차를 평균하고, 총소비 MAE는 항목을 합한 뒤 오차를 구합니다. 어떤 항목을 크게 예측하고 다른 항목을 작게 예측하면 총액에서는 차이가 상쇄될 수 있어 두 지표를 함께 봅니다. 반복 응답은 각각 채점한 뒤 오차를 집계했습니다.

95% 구간은 같은 가족에 대한 두 모형의 오차를 짝지어 재표집해 계산했습니다. 개발 단계의 탐색적 비교로, 여러 비교를 동시에 수행한 데 대한 보정은 적용하지 않았습니다.
