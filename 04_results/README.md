# 산출물 #3 · 1차 개발 실험 결과 및 오류 분석

[전체 모형 결과표](TABLES.md) · [기계 판독 CSV](metrics.csv) · [집단 수준 진단](diagnostics.json)

## 결과 읽기

- 1-A 기존98: CatBoost의 항목·총소비 MAE가 LLM보다 작음. LLM은 전년 소비 유지보다 소폭 개선
- 1-B 신규40: LLM의 항목 오차는 CatBoost와 비슷한 수준이고 총소비 오차는 비교 모형 중 가장 작음. 점추정치 순위만으로 유의한 우위를 단정하지 않음
- 1-B의 실제 평균 총소비 변화는 +91,769원, LLM은 −173,068원. 가구 간 변화 SD는 각각696,827원과310,167원. 금액 오차 순위와 변화 방향·분산의 재현은 별개
- 교육변화 추가53은 목적표집 진단이므로 기존98과 합쳐 대표 성능으로 보고하지 않음

## CatBoost 참고 LLM

공통96가구에서 기존 LLM 대비 항목 MAE 약9.7%, 총소비 MAE 약17.1% 감소. CatBoost 단독 대비 항목 MAE 약1.3% 증가, 총소비 MAE 약0.7% 감소. 항목 MAE 차이(참고 LLM−CatBoost)의95%구간은 약−3,227~4,284원으로 추가 우위 미입증

기존 LLM 대비 항목 차이는 약−4,768원,95%구간 약−8,679~−2,126원. 반복 응답 변동이 함께 줄었다는 결론은 아님. 외부 예측값의 효과와 LLM 자체 판단 향상을 구분하며, 설명의 유용성·정합성은 별도 평가 대상

## 과거 개선 실험과의 연결

[실험별 방법·파일·결과 대응표](../03_experiments/RESULT_LINKS.md)에 초기 RAG, 시점·분포 보강, 역할·절차 안내, 전항목 설명 결과를 별도 정리했습니다. 현재 결과표와 표본·문구·출력 형식이 다른 과거 결과는 통합 순위로 합치지 않습니다.

## 개선되지 않은 결과도 보존

과거 역할·절차 안내 실험에서는 기본 대비 항목 오차가 1-A 약1.79%,1-B 약2.47% 증가했습니다. 정보표까지 추가한 조건도 일관된 개선을 보이지 않았습니다. 최신98/40 결과와 표본·입력·시점이 달라 직접 개선량으로 연결하지 않습니다.

가구별 오류 검토에서는 큰 오차가 특정 항목·소수 사례에 집중되는 현상과, 실제 지출 발생 여부가 미관측일 때 기준액 유지로 이어지는 설명을 검토했습니다. 오류의 원인 가설과 실제 원인 입증을 구분합니다. 개별 가구의 금액·응답 원문은 공개하지 않습니다.

## 범위와 한계

현재 수치는 개발 실험입니다. 여러 변경에서 입력·표본·출력 형식이 함께 바뀌어 각 수정의 인과효과를 분리할 수 없습니다. 독립 최종 테스트, 외부 국가 데이터 평가, 설명의 유용성 평가, 2차 정책 시뮬레이션은 이 결과로 완료했다고 주장하지 않습니다.

`python3 scripts/render_results.py`로 집계 CSV에서 표를 다시 만들 수 있습니다. 원자료부터 성능을 재계산하는 완전 재현과는 다릅니다. 원 집계 파일의 해시는 PROVENANCE.json에 기록했습니다.
