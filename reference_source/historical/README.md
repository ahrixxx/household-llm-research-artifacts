# 개발 실험의 과거 버전

실제 사용한 공통 시스템 문안과 시점·분포 보강 코드를 원본 그대로 보존한 증빙입니다. 가구별 입력·소비 정답·응답은 포함하지 않습니다.

- `v5_*`: 초기 RAG 비교에서 사용한 original 문구의 시스템 문안; 실제 비교는 original/paraphrase 두 문구를 포함하며 두 파일만으로 모든 조건을 재현하지 않음
- `improved_20261016_*`: 시점·분포 보강 실험의 시스템 문안
- `v6_AB_20261017_*`: 역할·절차 안내 실험의 시스템 문안; A/B는 같은 시스템 문안이며 B의 차이는 입력 JSON에 추가한 가구 요약
- `code/`: 날짜 요약·검색 특성·분포 보조 정보 구성의 과거 구현; 전체 의존 모듈을 포함한 실행 패키지는 아님

[실험별 조건과 결과](../../03_experiments/RESULT_LINKS.md)를 함께 읽습니다. 과거 출력 형식은 발생확률·양수 평균·전체 중앙값이며 현재 단일 금액 형식과 구분합니다.
