# 이전 프롬프트와 보강 코드

이전 개발 실험에 사용한 프롬프트와 시점·지출 분포 보강 코드입니다. 파일은 당시 버전 그대로이며, 각 변경의 이유와 결과는 [개선 실험 기록](../../02_experiments/RESULT_LINKS.md)에서 설명합니다.

| 파일 | 사용한 실험 |
|---|---|
| `v5_*` | 초기 RAG 비교의 original 문구 |
| `improved_20261016_*` | 사건 시점·지출 분포 보강 |
| `v6_AB_20261017_*` | 역할·판단 절차 안내, B조건은 같은 문안에 가구 정보 요약을 입력 JSON으로 추가 |
| `code/` | 날짜 요약, 검색 특성, 지출 분포 정보 구성 |

초기 RAG 실험은 original/paraphrase 두 문구를 비교했으며, 이 폴더에는 original 문구를 보존했습니다. 당시 출력 형식은 발생확률·양수 평균·전체 중앙값으로, 현재의 단일 금액 형식과 차이가 있습니다.

가구별 입력·소비 정답·응답과 전체 의존 모듈은 포함하지 않았습니다.
