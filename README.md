**자료 정리 기준일: 2026-10-22 · 결과 기준: 2026-10-21까지 완료된 개발 실험**

현재 결과는 개발 실험이며 최종 독립 테스트나 실제 정책의 인과효과 추정 결과가 아닙니다. 목표연도 소득·가구 상태 등의 실현 정보를 제공하므로 순수한 사전 예측보다 **조건부 소비 재현**으로 해석합니다.

## 지금 실행할 수 있는 것

Python 3.10 이상, macOS/Linux, 표준 라이브러리만 사용합니다. Windows는 fcntl을 사용하는 기록 잠금 때문에 WSL 등 POSIX 환경이 필요합니다.

```sh
python3 scripts/render_results.py
PYTHONPATH=code python3 -m unittest discover -s code/phase2_monthly/tests -v
PYTHONPATH=code python3 -m phase2_monthly.demo --output outputs/synthetic-demo
```

첫 명령은 공개 집계에서 결과표를 다시 생성합니다. 나머지 명령은 기존 엔진을 합성자료로 검사하며 **실제 가구자료·API 키·유료 LLM 호출이 필요 없습니다**. 합성 데모의 B/C/D는 과거 엔진 점검 조건이며 최신 A/B/C/D0/D1 정책 실험의 완료 결과가 아닙니다.

### 그림과 실행 예시 재생성

```sh
python3 scripts/build_monthly_walkthrough.py
python3 scripts/plot_results.py
```

월별 예시는 표준 라이브러리만 사용합니다. 그림 생성은 `matplotlib`과 한글 글꼴이 필요합니다. macOS에서는 Apple SD Gothic Neo를 자동 선택하며 다른 환경에서는 해당 스크립트의 글꼴 설정을 설치된 한글 글꼴에 맞춰야 합니다. PNG·SVG·PDF 그림도 함께 제공합니다.

## 구현 범위

- `code/phase2_monthly/`: 원본과 동일한 기초 엔진 및 테스트, 독립 실행 가능
- `reference_source/`: 실제 연구에 사용한 대표 코드와 공통 프롬프트의 원본 발췌. 원자료·중간파일·일부 의존 모듈은 포함하지 않아 이 디렉터리만으로 전체 실험을 재실행할 수 없음
- `04_results/`: 개인 식별자와 소수 연도별 집계를 제외한 집단 수준 결과
- `scripts/`: 공개용 결과표 생성 도구. 연구 당시 실험 코드와 구분

원본 작업 저장소의 이력 전체를 포함하지 않고 공개 대상으로 선정한 파일만 제공합니다. 공개용 안내문과 예시 생성 코드는 당시의 실험 산출물과 구분합니다.

## 연구 방향

1차에서 1-A 일반 가구와 1-B 퇴직·소득 상실 관련 가구의 관측 소비를 비교합니다. 2차는 관측 소비의 정답이 없는 정책 시나리오 탐색입니다. 1차의 성능과 한계가 2차를 해석하는 범위를 정하며, 1차 성능만으로 정책 반응의 타당성이 입증되지는 않습니다.

코드·문서의 공개 열람을 위한 저장소이며 별도의 오픈소스 라이선스는 아직 부여하지 않았습니다. 외부 연구·데이터의 권리는 원저작자와 제공기관에 있습니다.
