# LLM의 가구 소비 재현과 지급조건별 시뮬레이션

한국노동패널(KLIPS)의 가구자료를 바탕으로, LLM이 가구의 경제적 여건을 받아 실제 소비를 얼마나 재현하는지 연구합니다. 소득·자산·가구 구성·과거 소비를 제공하고, 12개 항목의 소비금액을 실제 관측값 및 통계·머신러닝 모형의 예측과 비교합니다.

이 검증은 소득을 잃은 가구에 현금이나 소비 전용 지급금을 주었을 때의 선택을 시뮬레이션하기 위한 출발점입니다. 관측된 소비를 재현할 때 드러난 한계를 알아야, 정답이 없는 정책 시나리오의 결과도 해석할 수 있기 때문입니다.

도전학기제 중간보고를 위해 자료 처리 코드, 실험 기록과 결과를 공개했습니다. 현재 결과는 **2026년 10월 21일까지의 개발 실험**이며, 본실험용 최종 표본 배정은 진행 중입니다.

## 연구 구성

| 단계 | 분석 내용 | 현재 진행 상황 |
|---|---|---|
| 1차 · 소비 재현 | 일반 가구(1-A)와 퇴직 관련 가구(1-B)의 소비를 재현하고 기준선과 비교 | 입력·프롬프트 개선 및 개발 실험 완료, 본실험 준비 |
| 2차 · 정책 시나리오 | 소득 상실 상황에서 지급조건별 월별 소비·금융자산 경로 비교 | 기초 엔진 구현 및 합성자료 실행, 최신 정책조건 연결 준비 |

1차에서는 목표연도의 소득과 가구 상태도 입력에 포함합니다. 주어진 가구 여건에서 소비를 재현하는 **조건부 소비 재현** 과제입니다.

## 현재 결과

- **일반 가구 98가구(1-A)**: CatBoost의 항목 평균 오차와 총소비 오차가 LLM보다 작았습니다
- **퇴직 관련 40가구(1-B)**: LLM의 총소비 오차가 비교 모형 중 가장 작았지만, 평균 소비 변화의 방향과 가구 간 차이는 충분히 재현하지 못했습니다
- **CatBoost 예측을 참고한 LLM**: 공통 96가구에서 기존 LLM보다 항목 평균 오차는 9.7%, 총소비 오차는 17.1% 줄었습니다. CatBoost 단독보다 낫다는 근거는 뚜렷하지 않았습니다

[결과와 해석](03_results/README.md)에서 비교 그래프와 수치를 볼 수 있습니다. RAG, 판단 절차 안내, 항목별 설명 요청 등 개선 시도의 결과는 [실험 기록](02_experiments/RESULT_LINKS.md)에 남겼습니다.

## 실행 방법

Python 3.10 이상과 macOS/Linux 환경을 기준으로 합니다. Windows에서는 파일 잠금에 사용하는 `fcntl` 때문에 WSL 등 POSIX 환경이 필요합니다.

```sh
# 집계 결과로 표 생성
python3 scripts/render_results.py

# 월별 엔진 검사
PYTHONPATH=code python3 -m unittest discover -s code/phase2_monthly/tests -v

# 합성자료로 월별 시뮬레이션 실행
PYTHONPATH=code python3 -m phase2_monthly.demo --output outputs/synthetic-demo

# 계획·실행·반성 연결 예시 생성
python3 scripts/build_monthly_walkthrough.py
```

위 명령은 표준 라이브러리만 사용합니다. 실제 가구자료나 API 키 없이 실행할 수 있으며, 합성 실행에는 LLM 대신 정해진 시험용 응답을 사용합니다.

그래프는 `python3 scripts/plot_results.py`로 다시 그릴 수 있습니다. `matplotlib`과 한글 글꼴이 필요하며, macOS 외 환경에서는 스크립트의 글꼴 설정을 조정해야 합니다. 생성된 PNG·SVG·PDF는 [결과 폴더](03_results/figures)에 포함했습니다.

## 자료 이용

가구별 원자료와 개별 LLM 응답은 공개하지 않습니다. 따라서 이 저장소에서 실행할 수 있는 범위는 집계 결과의 표·그래프 생성과 합성자료를 이용한 엔진 검사입니다. KLIPS 기반 실험 전체를 다시 실행하려면 별도의 원자료와 의존 코드가 필요합니다.
