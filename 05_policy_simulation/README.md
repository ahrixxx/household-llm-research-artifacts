## 계획·실행·반성의 연결 구조

현재 상태와 과거 경제 경험을 참고하여 계획을 세우고, 실제 선택과 결과를 기록한 뒤 다음 계획에 반영하는 구조를 구현했습니다.

**매월: 현재 상태 확인·과거 경험 회상 → 향후 3개월 계획 갱신 → 이번 달 선택 → 제약 검사·집행 → 결과 기록**

**3개월마다: 직전 3개월의 계획·실행·결과에 대한 반성 → 다음 달 이후 회상과 계획에 제공**

| 단계 | 구현 내용 | 실제 사용 코드 |
|---|---|---|
| 기억·회상 | 현재 상황과 관련된 과거 경제 기록, 이전 계획, 최신 분기 반성과 그 근거 기록 제공 | [memory.py](../code/phase2_monthly/memory.py) |
| 계획 | 향후 3개월의 월별 계획을 매월 갱신하고 이전 계획의 유지·변경 이유를 별도 기록 | [engine.py](../code/phase2_monthly/engine.py), [단계별 지침](../code/phase2_monthly/contracts.py) |
| 선택·실행 | 계획을 참고하여 이번 달 소비·저축·투자 선택, 계획과 다를 때 이유 기록, 실행 가능한 거래 집행 | [engine.py](../code/phase2_monthly/engine.py), [ledger.py](../code/phase2_monthly/ledger.py) |
| 당월 수정 | 예산 등 실행 제약 위반 시 같은 월·같은 시작 상태에서 계획 수정과 재선택, 최초 선택은 보존 | [engine.py](../code/phase2_monthly/engine.py) |
| 경제적 반성 | 시뮬레이션 3·6·9개월 등 매 3개월 말에 해당 기간의 환경·계획·실행·결과를 돌아보고 이후 계획의 고려사항 생성 | [반성 지침·출력 형식](../code/phase2_monthly/contracts.py), [engine.py](../code/phase2_monthly/engine.py) |
| 다음 판단에 연결 | 생성된 반성을 다음 달부터 제공하며 관측 사실·실행 기록과 구분해 저장, 과거 장부는 유지 | [memory.py](../code/phase2_monthly/memory.py), [연결 검사](../code/phase2_monthly/tests/test_engine.py) |

계획은 3개월마다 한 번 만드는 것이 아니라 **3개월을 내다보며 매월 갱신**합니다. 반성은 매월이 아니라 시뮬레이션 시작 기준 매 3개월 말에 생성합니다. 24개월 말 반성은 종료 요약입니다. 당월 제약 위반 수정과 경제적 반성은 별도 단계이며, 오류 교정 이력은 이후 경제적 회상·반성에서 제외합니다.

이 구조는 코드와 합성자료 검사로 구현을 확인한 상태입니다. 반성을 제공했을 때 실제 LLM의 선택이나 결과가 개선되는지는 별도 비교가 필요합니다.

## 최신 설계 — 2026-10-21

| 조건 | 소득 상실 | 추가 지급 | 기한 |
|---|---|---|---|
| A | 없음 | 없음 | 해당 없음 |
| B | 있음 | 없음 | 해당 없음 |
| C | 있음 | 자유롭게 사용할 수 있는 현금 | 없음 |
| D0 | 있음 | 소비 전용 지급금 | 없음 |
| D1 | 있음 | D0와 같은 소비 전용 지급금 | 있음 |

소비 전용 지급금은 12개 소비항목 모두에 사용 가능합니다. 현금 전환·직접 예금·ETF 매수는 불가하며 별도의 비이자성 잔액으로 관리합니다. 기존 현금을 저축하는 것은 허용하므로 지급금 사용액을 추가 소비로 간주하지 않습니다. 구매처·가맹점·지역 선택은 주실험에서 구현하지 않습니다.

C−B는 현금 지원, D0−C는 지급방식의 복합 차이, D1−D0는 나머지 조건을 맞춘 기한 차이를 비교합니다. 실제 정책의 인과효과나 CBDC 기술 자체의 효과로 해석하지 않습니다.

## 공개한 기초 엔진

[엔진 코드](../code/phase2_monthly/)에는 월별 계획·결정·기록, 예산·회계 검사, 지급금 잔액·만료 관리, 기억·반성 단계와 합성자료 테스트가 포함됩니다. [실행 안내](../code/phase2_monthly/README.md)

**기존 합성 데모 B/C/D × 3/6/9개월은 기초 엔진 점검용**입니다. 최신5조건의 실증 결과가 아니며 D0 무기한 잔액 및 최신 조건 생성·금융계약 연결은 후속 구현 대상입니다. 현재 코드를 완성된 최신 정책 실험으로 부르지 않습니다.

## 남은 작업

무기한 잔액·종료 시점 처리, 최신 A/B/C/D0/D1 조건 연결, 지급·결제·이자 규칙의 정합성 검사, 실제 가구자료 연결과 예비 실행. 지급액·만료기간·표본·반복 수·비용은 실행 전에 확정해야 합니다.

24개월 월별 분석에서 누적소비,12항목 구성,현금·예금·ETF 경로 및 지급금 사용·잔액·만료를 관찰합니다. 금융자산 증가를 곧바로 후생 개선으로 해석하지 않습니다.
