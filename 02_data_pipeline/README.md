# 산출물 #1 · 가구 실험자료 구축 명세 및 대표 코드

## 진행 상태

가구자료 구성 및 개발용 표본 구축 완료, 최종 표본 배정 진행 중

현재 공개한 표본 수는 개발 실험에 사용한 구성을 나타냅니다. 본실험에 사용할 최종 학습·개발·평가 표본과 1·2차 역할 배정은 정리 중입니다.

## 자료와 처리 구조

출처: 한국노동연구원 한국노동패널(KLIPS). 원자료는 제공기관의 이용 절차에 따라 별도로 확보해야 합니다.

개인·가구 관측 연결 → 변수 시점·단위·결측 점검 → 과제별 사례 구성 → 연결가족 기준 역할 관리 → 모델 입력과 목표 소비 분리 → 공통 단위로 평가

| 정보 | 구성·점검 원칙 |
|---|---|
| 소비 | 식비, 외식비, 공교육비, 사교육비, 주거비, 보건의료비, 교양오락비, 내구재 구입비, 통신비, 피복비, 대중교통비, 생필품 구입비 |
| 가구 상태 | 가구 구성, 개인별 교육·취업 상태, 주거 상태 및 관측 시점 |
| 경제 여건 | 개인·가구소득, 보유자산과 가용자금. 결측을 0으로 임의 해석하지 않음 |
| 퇴직 관련 | 사건 시점, 퇴직 사유, 후속 취업·소득 정보. 퇴직 자체를 지속 소득 상실과 동일시하지 않음 |
| 단위 | 입력·응답의 귀속연도 명목금액을 명시하고 평가에서는 전국 CPI로 2023년 실질 원/월 환산 |
| 표본 배정 | 개발 실험별 학습·개발 구성을 관리하고 본실험용 최종 표본 배정 진행 중 |

## 실제 구현 증빙

- [1-A 사례 구성 원본](../reference_source/code/build_phase1a_cases_v1.py)
- [1-B 사례 구성 원본](../reference_source/code/build_phase1b_cases_v1.py)

두 파일은 초기 자료 구성 버전의 원본이며 이후 입력·표본 보완 전체를 대표하는 최종 단일 실행기는 아닙니다. 내부 경로·표본 수는 해당 버전의 기록입니다. 공개본에는 필요한 비공개 자료와 전체 의존 코드가 없어 직접 실행하지 않습니다.

## 최신 개발 결과에 대응하는 표본

- 1-A 기존 개발: 98가구
- 교육변화 추가 진단: 54가구 계획, 완전 3회 응답 53가구의 비교를 별도 보고
- 1-B 신규 개발: 40가구, 가구별 평가 대상 연도 자료 총 52건
- CatBoost 참고 LLM: 원98가구 중 세 번 모두 응답이 있는 공통96가구

1-A 기준선 최신 학습은 6,926사례·5,551연결가족입니다. 따라서 이를 단순히 '7,000가구'라고 부르지 않습니다. 1-B 최신 기준선은 488학습가족·543사건 자료를 사용했습니다.

소비 정답·가구 식별자·가구별 입력·개별 응답은 공개하지 않습니다. 표본의 상세 명부나 원자료 없이 이 저장소에서 원자료 기반 실험 전체를 재현할 수는 없습니다.
