# 01. 가구 실험자료 구축

한국노동패널(KLIPS)의 개인·가구 자료를 연결해 LLM과 기준선 모형에 제공할 입력을 만들었습니다. 가구자료와 개발용 표본은 구축했으며, 본실험의 학습·개발·평가 표본과 1·2차 연구에 사용할 최종 표본은 배정 중입니다.

## 자료 구성

개인의 퇴직이나 소득 변화가 가구 소비에 미치는 영향을 살펴보려면 다른 가구원의 소득과 부양 부담도 함께 알아야 합니다. 이를 위해 개인의 교육·취업 상태와 소득을 가구의 구성·자산·소비 정보에 연결하고, 각 정보가 어느 시점을 나타내는지 맞췄습니다. 일반 가구는 1-A, 퇴직 관련 가구는 1-B로 나누었습니다.

| 정보 | 처리 내용 |
|---|---|
| 소비 | 식비, 외식비, 공교육비, 사교육비, 주거비, 보건의료비, 교양오락비, 내구재 구입비, 통신비, 피복비, 대중교통비, 생필품 구입비의 12개 항목 |
| 가구 상태 | 가구 구성, 개인별 교육·취업 상태, 주거 상태와 관측 시점 연결 |
| 경제 여건 | 개인·가구소득, 보유자산, 가용자금 구성 및 결측값 구분 |
| 퇴직 관련 정보 | 사건 시점, 퇴직 사유, 후속 취업·소득 정보 확인 |
| 금액 단위 | 입력·응답은 귀속연도 명목금액 사용, 평가는 전국 CPI로 2023년 실질 원/월 환산 |
| 표본 관리 | 연결가족을 기준으로 학습·개발 역할 관리, 본실험용 최종 배정 정리 |

결측값은 임의로 0으로 바꾸지 않았습니다. 퇴직 사례도 이후의 취업·소득 상태를 함께 살펴, 퇴직 자체를 지속적인 소득 상실로 처리하지 않도록 했습니다.

## 개발 실험 표본

| 구분 | 평가 대상 |
|---|---|
| 1-A | 기존 개발 표본 98가구 |
| 교육변화 추가 진단 | 계획한 54가구 중 3회 응답이 모두 확보된 53가구 |
| 1-B | 신규 개발 표본 40가구, 가구별 평가 대상 연도 자료 총 52건 |
| CatBoost 보조 LLM | 기존 98가구 중 비교 조건의 3회 응답이 모두 확보된 공통 96가구 |

1-A 기준선의 최신 학습자료는 6,926사례·5,551연결가족, 1-B는 488학습가족·543사건입니다. 한 가족에서 여러 사례가 나올 수 있으므로 사례 수와 가족 수를 구분했습니다. 1-B의 52건도 52가구라는 뜻이 아니라, 40가구에서 평가한 연도별 자료의 수입니다.
