# 04. 월별 정책 시뮬레이션

2차 연구에서는 소득 상실 이후 지원 유무와 지급 조건에 따라 가구의 소비와 금융자산이 어떻게 변하는지 24개월 동안 비교할 계획입니다. 현재 구현한 부분은 매월 계획을 세우고 선택을 집행한 뒤, 그 기록을 다음 달 판단에 전달하는 기초 엔진입니다.

[합성자료 실행 예시](EXECUTION_EXAMPLE.md)는 정해진 시험용 응답으로 동작을 확인한 기록이며 **LLM 시연이 아닙니다**.

## 월별 판단 구조

매월 현재 경제 상태와 과거 기록을 받아 향후 3개월의 계획을 갱신하고, 그중 이번 달의 선택을 집행합니다. 3개월마다 지난 계획과 실제 결과를 돌아보는 기록인 '반성'을 생성해 다음 달부터 제공합니다.

| 단계 | 구현 내용 | 관련 코드 |
|---|---|---|
| 과거 기록 조회 | 현재 상황과 관련된 경제 기록, 이전 계획, 최신 분기 반성과 근거 기록 제공 | [memory.py](../code/phase2_monthly/memory.py) |
| 계획 | 향후 3개월 계획을 매월 갱신하고 이전 계획의 유지·변경 이유 기록 | [engine.py](../code/phase2_monthly/engine.py), [contracts.py](../code/phase2_monthly/contracts.py) |
| 선택·집행 | 이번 달의 소비·저축·투자 선택, 계획과의 차이 기록, 가능한 거래 집행 | [engine.py](../code/phase2_monthly/engine.py), [ledger.py](../code/phase2_monthly/ledger.py) |
| 당월 수정 | 예산 등 제약 위반 시 같은 시작 상태에서 계획 수정·재선택, 최초 선택 보존 | [engine.py](../code/phase2_monthly/engine.py) |
| 분기 반성 | 3·6·9개월 등 매 3개월 말에 환경·계획·결과를 돌아보고 다음 계획의 고려사항 생성 | [contracts.py](../code/phase2_monthly/contracts.py) |
| 다음 달에 반영 | 반성을 관측 사실과 구분해 저장하고 다음 달 계획 입력에 포함 | [memory.py](../code/phase2_monthly/memory.py), [연결 검사](../code/phase2_monthly/tests/test_engine.py) |

24개월 말의 반성은 다음 달 입력 없이 종료 요약으로 남깁니다. 예산 위반을 고치는 과정은 실제로 집행한 경제적 경험과 구분해 이후 회상·반성에서 제외합니다. 반성에서 새로운 해석을 내놓더라도 이미 집행한 거래와 잔액은 바꾸지 않습니다.

## 지급조건 설계

2026년 10월 21일 기준 설계는 다음과 같습니다.

| 조건 | 소득 상실 | 추가 지급 | 사용기한 |
|---|---|---|---|
| A | 없음 | 없음 | 해당 없음 |
| B | 있음 | 없음 | 해당 없음 |
| C | 있음 | 현금 | 없음 |
| D0 | 있음 | 소비 전용 지급금 | 없음 |
| D1 | 있음 | D0와 같은 소비 전용 지급금 | 있음 |

소비 전용 지급금은 12개 소비항목 모두에 사용할 수 있고, 현금 전환·직접 예금·ETF 매수는 제한합니다. 별도의 이자가 없는 잔액으로 관리하며, 구매처·가맹점·지역 선택은 주실험에 포함하지 않습니다. 지급금으로 기존 소비를 충당하고 자신의 현금을 저축할 수도 있으므로, 지급금 사용액과 추가 소비를 구분해 살펴봅니다.

C와 B에서는 현금 지원에 따른 차이, D0와 C에서는 지급방식에 따른 차이, D1과 D0에서는 다른 조건을 맞춘 상태에서 사용기한에 따른 차이를 비교합니다. 설정한 조건 아래의 시나리오 비교이며, CBDC 기술 자체의 효과나 실제 정책의 인과효과를 추정하는 설계는 아닙니다.

## 구현 상태와 다음 작업

[공개 엔진](../code/phase2_monthly/README.md)은 월별 계획·결정·기록, 예산·회계 검사, 지급금 잔액·만료 관리와 기억·반성을 포함합니다. 기존 B/C/D 조건과 3·6·9개월 기간을 조합한 합성 실행으로 기본 동작을 확인했습니다. 이 시험 조건은 위의 최신 A/B/C/D0/D1 설계와 다릅니다.

다음으로 무기한 지급금의 잔액과 시뮬레이션 종료 시점의 처리 방식을 구현하고, 최신 정책조건과 금융 규칙을 연결할 예정입니다. 이후 실제 가구자료로 예비 실행을 진행합니다. 지급액·만료기간·표본·반복 수·비용은 실행 전에 확정하며, 실제 LLM이 반성을 제공받았을 때 선택을 바꾸는지도 비교할 계획입니다.

분석에서는 누적소비와 12개 항목의 구성, 현금·예금·ETF 경로, 지급금의 사용·잔액·만료를 함께 볼 계획입니다. 금융자산이 늘었다는 이유만으로 가구의 생활이 나아졌다고 해석하지는 않습니다.
